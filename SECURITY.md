# Security Policy

## Supported Scope

This repository is an early-stage open-source project. Security fixes are best-effort.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

If you discover a security issue, contact the maintainer privately with:

- a description of the issue
- affected area or file
- steps to reproduce
- possible impact

Please allow time for the issue to be reviewed before public disclosure.
